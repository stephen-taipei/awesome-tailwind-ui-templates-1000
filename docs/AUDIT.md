## 響應式實測與追加修復

第一輪 Chromium 實測記錄了 98 份手機與 1 份桌機頁面橫向溢出。追加修改共 **93 份模板**，包含導覽的窄螢幕換列、表單重排、步驟導覽、分頁選項、側欄標頭位移、tooltip 方向、裝飾偏移、字級與四欄導覽重排。未使用全站 `overflow-x:hidden` 掩蓋內容。七欄月曆保留完整內容，放在有名稱、可鍵盤聚焦與捲動的獨立區域。

測量在視窗尺寸更新後等待兩個 animation frames，避免將尚未完成的 resize 重新排版誤判成持續性溢出。第二輪已通過 13 項瀏覽器測試，桌機溢出歸零；最後另修正 `hero-048`、`landing-035`、`nav-114` 的字體與欄寬。最終 CI **強制要求所有 1,043 份模板在 1440px 與 390px 的頁面橫向溢出為零**，但允許有明確邊界的元件內部捲動。這不等於所有中間尺寸、外部圖片與互動狀態已完成人工驗收。

## 視覺與架構決策

重新設計的是「發現與取用模板」的入口、分類導覽與預覽操作，不是把全部模板套用同一種配色。原模板的局部主題變數、既有 URL 與視覺方向保留。首頁卡片插圖明確標示 **Layout sketch**；實際設計在預覽器呈現，沒有把示意圖冒充真實截圖。

首頁使用獨立、小型 CSS 與原生 ES modules，不為目錄載入整套模板 CSS。預覽按需載入單一模板；不會同時建立上千個 iframe。收藏只存瀏覽器 localStorage，失效時降級為當次工作階段，不收集個人資料。新增入口與預覽器有 CSP、鍵盤可見焦點、減少動態效果及明暗外觀。

## 長期 CI 安全界線

正式工作流程使用唯讀 repository token、固定 commit SHA 的 GitHub Actions，以及不保存 Git 認證的 checkout。CI 只執行建置、測試、依賴檢查與 artifact 上傳；不自動提交、推送或部署。建置後產生檔若與 Git 不一致會阻擋檢查。歷史 `plan.md` 保留為原始企劃，實際內容以 `templates.json` 與本報告為準。

## 重現

```sh
npm ci
npm run build
npm test
npm run audit
npx playwright install --with-deps chromium
npm run test:browser
```

`npm run migrate` 用於舊依賴格式；已遷移版本應無新增變動。CI 的最終一般驗證流程使用唯讀 repository token，不自動修改 main、部署或覆寫工作檔案。修復工作期間使用的臨時分支建置步驟不屬於長期工作流程。
